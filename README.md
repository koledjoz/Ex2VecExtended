# Ex2VecExtended

Inspiration for the code, notebooks, and scripts used to prepare data, train models, and create outputs can all be found in the other_files directory.

The main code used for training can be found inside the src directory. The training scripts and models outside of the optimized directory under models were used during the initial stage of exploration and experimentation. The models inside the optimized directory work the same way but have been optimized in order to run faster.

Other scripts and notebooks used during analysis and visualization can be found in the analysis_code directory, either directly inside or in the plotting subdirectory.


The notebooks inside the analysis_nb were used during the initial stages of analysis, and the actual code to calcualte results and visualisations was inspired by them.
