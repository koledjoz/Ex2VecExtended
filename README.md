# Ex2VecExtended

Inspiration for the code, notebooks and scripts used to prepare data, train models and create outputs, can all be found in the other_files directory.


The main code used for training can be found inside the src directory. The training scripts and models outside of the optimized directory under models were used during the initial stage of exploration and experimentation. The models inside optimized directory work the same way but have been optimized in oreder to run faster.

Ohter scripts and notebooks used during analysis and visualisatyion can be found in analysis_nb directory, either directly inside or in the plotting subdirectory.
